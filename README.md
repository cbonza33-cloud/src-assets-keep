# Pholeric - African Beauty E-commerce

A high-performance, mobile-first web application designed for a premium African beauty brand. This project focuses on accessibility, seamless local commerce, and professional documentation for small business growth.

## 🌟 Key Features
*   **Mobile-First Design:** Optimized specifically for mobile browsing and "Add to Home Screen" usage.
*   **WhatsApp Checkout:** Integrated primary communication channel for direct transactions and order management.
*   **Automated Tax Invoices:** Generates professional, printable receipts for every order with unique tracking numbers.
*   **Product Badging:** Dynamic visual cues for "Bestsellers" and special bundle deals.

## 🛠️ Technical Stack
*   **Frontend:** React.js
*   **Deployment:** Netlify for automated web hosting.
*   **Version Control:** GitHub for repository management and workflow.

## 📁 Project Structure
*   `src/assets/`: Contains high-quality product imagery.
*   `public/`: Static assets and the optimized `index.html` with mobile meta tags.
